# OG-Asset Archive

This folder archives the original ("OG") assets that were previously replaced or upgraded in the project, preserving them safely so they are never lost.

### Contents:
1. `classicBoat.js`:
   - Original Classic Player Boat ("OG Skin") with the twin machine guns, cabin rocket pod, cone bow, and warm hull.
   - Preserves original proportions, materials, and geometry.
   - Can be used interchangeably with the new Sunfire Hero boat in-game via the Settings menu or by pressing `O`.

2. `og_island_assets.js`:
   - Original versions of procedural island assets:
     - `makeOriginalRowboats`
     - `makeOriginalTreasureChest`
     - `makeOriginalTent`
